# 16. Ризик-рушій

## Що є

- Kill zone strict/soft (`KILL_ZONE_MODE`).  
- Circuit: N стопів / денний DD (env, дефолт 3 лосси / 4%).  
- Дарина: новини, RR, gerchik, ATR veto без sweep.  
- Кореляція відкритих `ACTIVE` (не WATCHING).  
- Промпт: RR ≥ 1:2, стоп за структуру, не рухати проти позиції.  
- `score_hint` 8–18 для snapshot.

## Stop buffer

У промптах «невеликий буфер». **Немає** статистичного buffer по ATR/сесії/типу сетапа.  
Історичне «спочатку вибило стоп, потім пішло» — **НЕ ВСТАНОВЛЕНО**.

## REVIEW vs ризик позиції

Немає гілки «оцінити чужий сигнал без журналу позиції». Ризик-модуль думає категоріями входу столу.

## $1000 психологія

Віктор згадує дисципліну; **немає** жорсткого cap ризику в $ на ручний аналіз (сканер старого каналу мав 1–3% — інша система).
