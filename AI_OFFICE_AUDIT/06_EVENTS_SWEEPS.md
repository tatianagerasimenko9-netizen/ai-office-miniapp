# 06. Події та sweep (доповнено)

Аудит не починався заново. Нижче — що офіс **мав** ловити vs що **зробив**.

## Цільовий ланцюг (вимога 2.0, у коді ABSENT)

```
MENTION → SETUP → WATCHING → PRE-ALERT (підхід) → EVENT (touch/sweep)
  → CONFIRMATION → SIGNAL → ENTRY → TP/SL → RESULT
```

Зараз у коді лише уламки: текст LLM + `office_signals` WATCHING/ACTIVE/HIT_*/EXPIRED.

## Що офіс мав відстежити (за власними словами агентів)

| Подія | Джерело вимоги | Чи є детектор | Чи повідомив Тетяну вчасно |
|-------|----------------|---------------|----------------------------|
| Ціна в названій зоні | Олеся «повідомлю як ціна дійде»; monitor | Poll proxy-ціни vs entry_low/high | Лише якщо рядок WATCHING живий і є notify |
| Sweep іменованого BSL/SSL | Лев «чекаю sweep вище 87247» | Ні. Є лише 1h wick-патерн на виклику tool | Ні в кейсі 23.09 07:35 |
| Підтвердження H1 | Текст Лева | Ні як стан | Ні |
| ATR_DEAD | Код monitor >90% | Так, expire рядка | Часто **без** явного алерту «більше не дивлюсь» |
| Підхід до зони (ще не sweep) | Вимога 2.0 PRE-ALERT | ABSENT | Ні |
| Сесійний хай/лоу як named level | Банери Азії | Банер ≠ підписка | Банер 03:02 23.09 не про 87247 |

## Де загубився «сигнал» (типові дірки)

1. **Зона лишилась у прозі** — Лев написав цифри всередині ПРОПУСКУ, парсер не зробив watch **або** watch без SL/TP крутить reanalyze, а не event.  
2. **Не той символ у сканері** — BTC/ETH excluded.  
3. **Не той ТФ** — sweep 5m/15m, детектор 1h post-fact.  
4. **Не той час poll** — поза KZ 15 хв.  
5. **Ручний MENTION** вважають автономним SETUP (AKE).  
6. **Чужий сигнал сканера** у MAIN може піти в `office_handle_signal`, а текст Лева в офісі — інший контур (`full_auto_analysis`). Два світи, різні статуси.

## 804 «сигнали»

У зовнішньому чернетковому аудиті ChatGPT: «Лев згадував LONG/SHORT/вхід/сетап 804 рази».

Повторний підрахунок по JSON чату AI Office: повідомлень Лева з токенами LONG/SHORT/ЛОНГ/ШОРТ/сетап/вхід = **472 / 3849**. Карток формату сигнал ≈ **4**.

**804 не підтверджено.** Навіть 472 — це MENTION, не SIGNAL. Не розкладати 804 по етапах MENTION→… як фактичну статистику.
