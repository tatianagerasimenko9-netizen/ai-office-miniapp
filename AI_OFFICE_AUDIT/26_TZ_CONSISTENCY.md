## 6. Точне ТЗ задачі №1 (T0) — після команди «МОЖНА ВНОСИТИ ЗМІНИ»

**Назва:** `ZONE_REACHED` не залежить від ATR / Edge / SIGNAL.

**Root cause (код, не чат):** `monitor_active_signals` у `office_relay_wizard.py`:

```
якщо status==WATCHING і day_used_pct>90:
    signal_update(..., status=EXPIRED, outcome=ATR_DEAD)
    continue   # ← жодного send_office
```

Далі notify «ЦІНА В ЗОНІ» існує (рядки ~4728 і ~4746), але **після** цього `continue`. IRYS 13.05: Олеся «Повідомлю як ціна дійде» → Тетяна «Чому не повідомила???» → Лев «Не повідомила бо не було A+».

**Файли (лише ці, без промптів агентів якщо можна):**

- `office_relay_wizard.py` — гілка ATR_DEAD у моніторі;
- опційно `office_bridge.py` — статус `ZONE_REACHED` **або** event у `office_events` (не міграція обов’язкова в T0: можна залишити WATCHING і лише надіслати повідомлення);
- новий `scripts/test_zone_reached_notify.py` — офлайн, без мережі.

**Не чіпати:** `file-1`, CONFIG порогів, edge 85, kill zone, LLM system prompts, Mini App, схему Postgres окрім опційного event.

**Поведінка після зміни**

1. Ціна в entry-діапазоні WATCHING → **завжди** одне повідомлення шаблону: символ, ціна, зона, `ATR=…`, `SIGNAL=NO|YES`, причина.
2. Якщо ATR>90 або Edge<порогу: `SIGNAL=NO`, статус зони **не ховати** мовчки в `EXPIRED` до сповіщення. Після сповіщення можна `EXPIRED` + cooldown.
3. Текст «входь!» **заборонений**, якщо SIGNAL=NO (зараз рядок 4751 штовхає вхід).
4. Повтор того ж `signal_id` + `ZONE_REACHED` — не частіше cooldown (існуючий `_allow_notify`).

**Тести**

- Фікстура: WATCHING, ціна в зоні, `day_used_pct=95` → виклик send **1 раз**, текст містить `ZONE_REACHED` або «зону досягнуто», **не** містить «входь!».
- Фікстура: ціна поза зоною → 0 notify.
- `python3 -m compileall office_relay_wizard.py`

**Ризики**

- Більше алертів на широких зонах (CLUSDT 88–101 уже спамив «ЦІНА В ЗОНІ»). Mitigation: cooldown + одна подія на `signal_id`.
- Не ламає форвард SOURCE і LLM-діалог: гілка монітора окрема.
- Не блокує сканер (T5 ще немає) — **свідомо**.

**Rollback:** revert коміту T0; ATR знову глушить без алерту (старий баг).

**Чому не T4 першим:** T4 не змінює чат і не лікує IRYS. T4 **обов’язковий перед T5**, але P0 користувача — зв’язок «обіцяв стежити → ринок → повідомлення».
