# Індекс карток Булковскі (архів Patterns)

Архів `Bulkowski/Patterns/*.docx` — розбір Encyclopedia of Chart Patterns по фігурах. **Оригінальні docx у git не кладемо.**

Геометрія родин — у `KONSPEKT_UA.md`. Нижче — повний перелік унікальних карток з архіву (дублікати злито).

> Агенти **не цитують** failure rate / середній % / throwback з карток. Стоп «0.15» з акцій США **не переносити** на крипту/XAU.

**У архіві без тексту:** Gaps, Rounding Bottom (ймовірно лише картинки) — дивись `KONSPEKT_UA.md`.

## Наскрізні правила (для всіх фігур)

1. Патерн «вмикається» лише **пробоєм** (закриття за межею).
2. Throwback (після пробою вгору) / pullback (вниз) часто **погіршують** подальший хід — або вхід на пробої, або після завершення відкату.
3. **Busted** (пробій зірвався) = сильний хід у протилежний бік = хибний пробій Герчика.
4. Measure rule: висота фігури від точки пробою; у офісі ціль не менша за **3R** Герчика, інакше пропуск.
5. Обсяг часто спадає всередині фігури; сплеск на пробої — підтвердження, не окремий «чорний ящик».
6. Adam = гострий шип; Eve = округла форма (подвійні дна/вершини).
7. Partial rise / partial decline всередині прямокутника/розширення — натяк на бік пробою **до** виходу; все одно чекати закриття.

## Звʼязок з Герчиком

Булковскі → гіпотеза фігури. Герчик → чи межа = рівень D1, чи є ATR, чи є імпульс/ЛП, чи RR≥3.

## Для Марічки (вечір)

На D1/4H назвати **не більше 1–2** фігур, якщо межі = рівні Герчика. Інакше мовчати про «патерн».
