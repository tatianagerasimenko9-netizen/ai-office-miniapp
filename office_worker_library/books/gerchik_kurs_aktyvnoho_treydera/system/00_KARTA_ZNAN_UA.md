# Карта знань книги Герчика

Формат, зафіксований у ТЗ:

```
Герчик
├─ Рівні
├─ Імпульси
├─ ATR
├─ Хибні пробої
├─ Ризик-менеджмент
├─ Психологія
├─ Торговий план
└─ Алгоритм прийняття рішень
```

Розгортка файлами `system/`:

```
Герчик
├─ Рівні
│  ├─ 01 підтримка/опір
│  ├─ 02 сильні/слабкі
│  └─ 03 дзеркальні
├─ Імпульси (04)
├─ Консолідація (05) / накопичення (10)
├─ ATR (11)
├─ Хибні пробої (06) / хибні сигнали (23)
├─ Відбій (08) / пробій (09) / повернення (07)
├─ Ризик-менеджмент (13)
│  ├─ Мані-менеджмент (14)
│  └─ RR 3:1 (15)
├─ Психологія (16) / помилки новачків (17)
├─ Торговий план (12)
└─ Алгоритм прийняття рішень
   ├─ Вибір інструментів (18)
   ├─ Підготовка дня (19)
   ├─ Аналіз графіка (20)
   ├─ Вхід (21) / стопи (24) / тейки (25)
   └─ Вихід (22)
```

Вхід: `00_YAK_CHYTATY_UA.md` (шари А/Б/В).
