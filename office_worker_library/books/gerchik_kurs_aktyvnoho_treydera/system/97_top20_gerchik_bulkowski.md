# ТОП-20 комбінацій Герчик + Булковскі

Лише **геометрія**. Без % надійності Булковскі.

1. ЛП + Double Top/Bottom (прокол другого екстремуму).
2. Рівень D1 + Head and Shoulders (шия = рівень).
3. ATR-фільтр + Pennant (вихід, поки бак не порожній).
4. Імпульс + Flag (флагшток = імпульс стопів).
5. Накопичення + Rectangle.
6. Дзеркало + Cup and Handle (ретест ручки/краю).
7. Поджатие + Ascending/Descending Triangle (горизонтальна сторона = рівень).
8. Паранормальний бар на рівні + Pipe/Horn (шип), лише з підтвердженням Герчика.
9. Злам тренду + Rounding Top/Bottom як контекст, вхід лише від рівня.
10. Локальний перехай + Rising Wedge (обережно: клин Булковскі ≠ обовʼязковий сигнал Герчика).
11. Пробій + Rectangle breakout.
12. Відбій + Triple Top без пробою.
13. Складний ЛП + busted breakout.
14. Канал ≥6–8 стопів + Rectangle swing.
15. Геп на пробої + Breakaway gap (типи гепів збігаються за логікою).
16. Геп виснаження + Dead-Cat Bounce як **не** розворот одразу.
17. Ретест + Throwback/Pullback.
18. Measured Move: друга нога лише якщо ATR і рівень дозволяють 3:1.
19. Symmetrical Triangle + поджатие Герчика; вхід за пробоєм/ЛП, не «вгадування боку».
20. High and Tight Flag лише якщо після імпульсу ATR дня не вичерпано.

Ланцюг: **спочатку патерн як гіпотеза → рівень Герчика → ATR → ЛП/імпульс → RR/стоп.**
