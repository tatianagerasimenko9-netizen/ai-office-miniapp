# Чек-лист трейдера перед відкриттям позиції

Відмічати **так/ні**. Будь-яке «ні» без винятку з алгоритму = немає входу.

## Рівень і контекст
- [ ] Рівень з **D1** (або старшого), не індивідуальний
- [ ] Тип рівня визначено; **не плаваючий**
- [ ] Глобальний і локальний тренд записані (збіг — плюс)
- [ ] Фаза: тренд / флет / новини

## Модель
- [ ] Обрано **одну**: відбій / пробій / хибний пробій
- [ ] Є підтвердження (БПУ / закриття / імпульс за правилами моделі)
- [ ] Немає слому моделі

## ATR і RR
- [ ] ATR за 3–5 днів без паранормальних
- [ ] Технічний ATR ≥ розрахункового
- [ ] ATR ≥ 5 стопів
- [ ] Пройдено <75–80 % ATR **або** виняток екстремуму
- [ ] Тейк ≥ 3R і не впирається в ближчий сильний рівень без плану

## Ордери й ризик
- [ ] ТВХ з люфтом порахована від **ціни входу**
- [ ] Стоп технічний (крипта — лише технічний) за укриття
- [ ] Лот з денного ліміту (поділ на 3–5)
- [ ] Сьогодні < 3 збитків підряд
- [ ] Крипта: BTC-контекст; лімітка / заявка заздалегідь; стоп не «посуну»

## Дисципліна
- [ ] Є письмовий сценарій A/B
- [ ] Вхід не з помсти і не щоб «округлити»
