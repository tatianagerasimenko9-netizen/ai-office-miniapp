# ТОП-10 сетапів Герчика для крипти

**Шар Б:** моделі **з книги**, контекст — крипта з розділу особливостей. Без вигаданих цін як «обовʼязкових рівнів Герчика».

1. **ЛП сильного D1** (простий / двома барами / складний) + технічний стоп за хвіст — пряма вказівка книги для крипти.
2. **Відбій БСУ/БПУ** від очевидного рівня, лімітка з люфтом.
3. **Дзеркало** після пробою й закріплення, ретест.
4. **Пробій після поджатия/малих барів**, заявка заздалегідь, імпульс.
5. **Накопичення (вузький коридор) → вихід** імпульсом або ЛП межі.
6. **Альт vs BTC:** формація + альт сильніший/слабший за BTC (книжкові бали 1–2).
7. **Вихід альта з каналу аномального обсягу** (бал 6).
8. **Злам тренду на рівні** (книжкові **3 бали**) + підтвердження.
9. **Стоп-імпульс:** істинний пробій, коли знесені стопи за рівнем (імпульс є).
10. **Новинний імпульс лише після** рівня/закріплення; не догон на порожньому ATR (новини в алгоритмі крипти + ATR-правило).

Не з книги як окремі сетапи: «Short Squeeze» як назва, CME-геп, «cusp» як термін — не використовуємо як цитати.
