# Дерево прийняття рішень для торгового бота

```text
[Старт]
 ├─ Домашка/сценарій є?
 │   └─ НІ → СТОП
 ├─ Ліміт дня / 3 збитки?
 │   └─ ТАК (ліміт вичерпано або 3 SL) → СТОП
 ├─ Ціна біля рівня D1 і рівень не плаваючий?
 │   └─ НІ → наступний символ
 ├─ ATR: tech≥calc і ≥5 стопів?
 │   └─ НІ → ПРОПУСК
 ├─ ATR_used ≥75–80% і НЕ виняток екстремуму?
 │   └─ ТАК → не по тренду; шукати контртренд/ЛП або ПРОПУСК
 ├─ Модель?
 │   ├─ Відбій (БПУ, не поджатие) → лімітка
 │   ├─ Пробій (малі бари + імпульс) → stop-ордер за рівень
 │   ├─ ЛП (немає імпульсу + повернення, глибина ≤1/3 ATR) → stop на поверненні
 │   └─ Немає → ОЧІКУВАННЯ
 ├─ RR≥3 і лот з ризику?
 │   └─ НІ → ВЕТО
 └─ [ЗАЯВКА] → стоп одразу → тейк
```
