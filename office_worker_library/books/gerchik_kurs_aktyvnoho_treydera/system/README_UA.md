# Практична система Герчика (офіс)

Структурована база для навчання агентів і ручної торгівлі **криптовалютами** та **XAUUSD**.

## Як читати

1. `00_YAK_CHYTATY_UA.md` — шари А/Б/В, що **не** з книги.
2. Теми `01`–`25` — єдина структура (15 пунктів + блоки практики).
3. Додатки `90`–`99`.
4. Базовий наративний конспект: `../KONSPEKT_UA.md`.

**Код офісу цим шаром не змінюється** (немає правок `LEV_RULE` / сканера). Це навчальні документи.
