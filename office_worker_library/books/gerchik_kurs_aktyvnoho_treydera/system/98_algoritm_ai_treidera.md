# Повний алгоритм AI-трейдера (шар Б на правилах книги)

1. **Universe:** ліквідність; крипта — BTC + топ обсяг; ATR ≥ 5 стопів.
2. **D1 scan:** інструменти біля рівнів; тип рівня; не плаваючі.
3. **Поводир:** BTC (книга); золото — окремо як 24h, не «альт BTC».
4. **ATR_used:** якщо >75–80 % — заборонити тренд-вхід (крім винятку).
5. **Model:** відбій / пробій / ЛП за правилами глав 3 і 5.
6. **Score:** або книжкова крипто-шкала (≥5), **або** ops 0–10 — не змішувати без позначки.
7. **Math:** люфт, ТВХ, технічний стоп, тейк ≥3R, лот від денного ризику.
8. **Order:** тип ордера = модель; крипта — лімітка/заздалегідь.
9. **Veto:** Дарина-логіка: ліміт дня, 3 збитки, tech_atr, RR.
10. **Journal:** після виходу поля слому/емоції.

**Булковскі → Герчик → агент**
1. Знайти фігуру (гіпотеза).
2. Чи межі = рівні D1 Герчика.
3. ATR.
4. Чи був ЛП / імпульс.
5. Бали.
6. Стоп за укриття.
7. Тейк ≥3R.
8. JSON на виконання (людина підтверджує в офісі, доки немає окремого ТЗ на автоторгівлю).
