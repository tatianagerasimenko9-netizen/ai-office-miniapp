# Торгова система Герчика на одній сторінці

1. **D1:** тренд, сильні рівні, ATR (3–5 днів, без паранормалу), технічний vs розрахунковий ATR.
2. **Сценарій:** одна модель — відбій (БСУ/БПУ, лімітка), пробій (малі бари, stop-ордер), ЛП (немає імпульсу + повернення).
3. **Математика:** стоп від структури; ризик від ціни входу; люфт 20 % стопа (або 0,04 % ціни); тейк ≥ 3R.
4. **Фільтри:** не плаваючий; не 75–80 % ATR по тренду; не затискання між денними без пробою.
5. **Виконання:** ордер → стоп одразу → тейк; слом → скасувати.
6. **Капітал:** 1–3 % день (часто 1 %), 3–5 угод, 3 стопи = стоп-день.
7. **Крипта:** ті самі рівні; BTC; не рухати стопи; лімітки; стоп до 2 % розрахунково / технічний за хвіст ЛП.
8. **Золото:** як 24h товар + ранковий фʼючерс у макро; правила рівнів ті самі.
9. **Після:** журнал, статистика, не відіграш.
10. **БЕ:** не догма; середня статистика книги проти частого BE — дивись уточнення.
