# ТОП-10 сетапів Герчика для золота (XAUUSD)

**Шар Б.** Книга не дає 10 золотих сетапів. Нижче — універсальні моделі книги + 24h-застереження.

1. Відбій від D1 лімітника / історичного.
2. Дзеркало після імпульсного пробою.
3. ЛП круглого числа (круглі числа — правило книги загальне).
4. Складний ЛП кількома барами (глибокий набір).
5. Консолідація під опором → пробій малими барами.
6. Відбій великими барами в рівень (не пробій).
7. Імпульс після пробою каналу + перше повернення (ретест), не догон.
8. Геп виснаження **не** торгувати як продовження (тип гепа з гл. 1).
9. Рівень з паранормального хвоста — лише з підтвердженнями.
10. Після новини — повернення в канал/проторговку, не перший сплеск (логіка «не доганяти» + 24h).

Ранок: подивитись фʼючерс золота (пряма вказівка розкладу), потім ті самі D1-рівні спота/CFD, яким торгуєте.
