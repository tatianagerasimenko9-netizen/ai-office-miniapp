## Запустити бота

Зайти на Render -> твій сервіс -> кнопка Start.

## Зупинити бота

Render -> твій сервіс -> кнопка Suspend.

## Переглянути логи

Render -> твій сервіс -> вкладка Logs.

## Бот мовчить - що робити

1. Відкрити логи на Render.
2. Знайти рядки зі словом `SKIP`.
3. Сфотографувати і показати розробнику.

## Зберегти зміни в коді

У Cursor -> Source Control -> написати коментар -> Commit -> Push.

## Оновити дату в назві папки

Двічі клікнути на `UPDATE_DATE.bat`.
