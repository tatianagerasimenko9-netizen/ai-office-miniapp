# Пам'ять бота

Ця папка зберігає все важливе про бота:
- правила роботи;
- ролі;
- архітектуру;
- останні зміни;
- проблеми та рішення;
- швидкі щоденні дії.

## Головне

- Працюємо простою мовою.
- Без команди `пиши` код не змінюємо.
- Усі важливі зміни записуємо у `ЗМІНИ.md`.

## Що робити при старті нового чату

1. Відкрий `ПРАВИЛА_РОБОТИ.md`.
2. Відкрий `ЗМІНИ.md`.
3. Відкрий `ПРОБЛЕМИ_ТА_РІШЕННЯ.md`.
4. Дай коротке завдання: що перевірити або що змінити.
