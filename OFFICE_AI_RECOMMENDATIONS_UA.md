## 7. ChatGPT — критика «офісу»

**Що добре:** ролі, реакція на подію, канали, короткі повідомлення.

**Проблема:** немає спільного рішення; немає сигналу як центру; немає ланцюжка «сигнал → дискусія → рішення»; Лев повторює фрази замість збору думок.

**Як має бути (приклад):** Назар про ризик → Лев координує → Макс ліквідність → Софія статистика → Дарина ризик % → Лев фінал «ВХІД/ЧЕКАЄМО/ІГНОР».

**Канали:** у відео все в одному General; рекомендація — один головний чат, інше — лог.

**Що зробити:** сигнал з entry/SL/TP; Лев відкриває; черга Макс → Назар → Софія → Дарина; обов’язковий фінал від Лева.

## 8. ChatGPT — brain агентів

**Головне правило для всіх:** частина команди; читати інших; доповнювати, не повторювати; 1–3 рядки; без води; якщо нічого додати — мовчати.

Окремо: **Лев** — координація, фінал «Рішення: ВХІД/ЧЕКАЄМО/ІГНОР»; **Макс** — ліквідність/funding/об’єм, без рішення про вхід; **Назар** — новини; **Софія** — тільки реальні дані бази/історії; **Марко** — план entry/SL/TP/RR; **Дарина** — ризик і вето; **Олеся** — статус угоди/PnL.

**Порядок:** Лев старт → Макс → Назар → Софія → Дарина → Марко → Лев фінал; після рішення Марко + моніторинг Олесі.

## 11. ICT / FVG / CHOCH / комбінації

*(Нижче — об’єднаний текст без повторів одного й того ж абзацу.)*

### ICT розворот

Зміна напряму після збору ліквідності; типи: **Judas Swing** (sweep + закриття з іншого боку), **CHOCH + OB**, **Mitigation/Breaker**, **FVG + displacement**.

### FVG reversal

FVG як дисбаланс і магніт ціни; bullish/bearish сценарії; failed FVG (wick-hunting). Приклади: KGEN, ETH, POWER failed.

### CHOCH

Зміна «характеру» структури; BOS; відкат у зону. Приклади: SOL, BTC, failed POWER.

### Комбінації (пріоритет з оригіналу)

- CHOCH + FVG + Breaker Block — найвища якість  
- Judas + FVG — дуже сильна  
- FVG + Mitigation — надійна  
- Чистий Judas — слабше без FVG  

Додатково в матеріалі: **FVG + Judas**, **FVG + CHOCH**, **FVG + Mitigation**, **FVG + Breaker**, triple confluence, **Mitigation + EQ**, **Mitigation після новин**, **Mitigation + Liquidity Grab**, **CHOCH + Mitigation**, **failed Mitigation**, **Liquidity Grab** (успіх і фейл), **failed CHOCH + FVG / + Mitigation**, **FVG + Breaker + Liquidity Grab**, **CHOCH + Judas + FVG**, **Mitigation + Liquidity Grab**.

У кожному прикладі в оригіналі: сесія, структура пунктами, funding/об’єм/ATR, вхід/SL/результат, висновок або урок для failed.
