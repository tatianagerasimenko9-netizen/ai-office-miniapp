# Преддекларація гіпотез для test (зафіксовано ДО перегляду test-результатів цих підмножин)

Правило: гіпотеза формулюється й комітиться тут до того, як її test-результат надруковано; оцінюється **один раз** на test (і лише потім — на hold-out зафіксованої версії). Вердикт публікується незалежно від знаку. Підстава — діагностика на TRAIN (run 37288579099), без зазирання в test цих підмножин. Кількість порівнянь у діагностиці велика (≈25 груп), тож будь-яка «знахідка» з train — лише кандидат.

| ID | Гіпотеза | Визначення | Апріорна підстава | Критерій успіху на test |
|---|---|---|---|---|
| H1 | Фейд sweep має сенс лише ПО тренду H4 | базові кандидати (reclaim), `reg4·напрям > 0` | train: за трендом +0,4 п.п. проти −12,0 проти тренду; логічно: розворот у бік тренду, а не проти | надлишок test ≥ 0 з кластерним ІВ, що не лежить повністю нижче 0; R після комісій > 0 |
| H1b | H1 + BTC не проти (S2) | H1 і `btc_ok` | S2 слабко покращував test (−4,6 проти −6,3) | те саме |
| H2 | Помірна глибина sweep 0,3–1 ATR15 | базові кандидати, `0,3 ≤ depth_atr < 1` | **низька апріорна підстава (data-mined)**: train −1,9 проти −9,1 (<0,3) і −10,7 (≥1) | те саме; не приймати без H1-подібного логічного пояснення |
| H3 | Контр-гіпотеза «sweep частіше продовження»: дзеркальна угода | для базових кандидатів у режимі «проти тренду H4» увійти В НАПРЯМКУ пробою (SL і TP — дзеркально, відстані ті самі) | train: проти тренду −12,0 п.п. (багато продовжень) | надлишок test > 0 (ІВ вище 0 для вирішеності); це **нова стратегія** — приймається лише при стабільності train+test+hold-out |

Не реєструються й не перевіряються: пороги сесій (NY/Азія), типи рівнів (PWH/D1SW) — без логічної підстави, лише описова діагностика.
