# Аудит Price Action (Герчик) / SMC у коді Office2 — 11.10.2026

Метод: читання `office2/brain.py`, `brain2.py`, `levels.py`, `smc/`; без припущень. «Є» = реалізовано й працює в Brain v2.1; «частково» = є частина; «немає» = не реалізовано (не вигадуємо).

| Компонент (з завдання) | Статус | Де / примітка |
|---|---|---|
| Сильний горизонтальний рівень | частково | `all_levels`: сесійні (ASIA/LONDON/NY), swing M15/H1/H4/D1/W1, PDH/PDL/PWH/PWL/PMH/PML; `strength` = кількість майже рівних екстремумів (EQH/EQL). Немає оцінки за реакціями, обсягом, свіжістю |
| Підтримка/опір, локальний екстремум | є | swing-детектор (fractal n=2) |
| Дзеркальний рівень | немає | role-reversal явно не моделюється |
| Хибний пробій / sweep + повернення | є | `SWEEP_SEQ`, `SWEEP_RECLAIM` (модель REJECTION) |
| Справжній пробій + закріплення + ретест | частково | `pullback_break` (v1) у v2.1 лише як джерело ORIGIN_SEQ (≈7 % подій replay); окремої живої моделі BREAKOUT+RETEST немає (див. KNOWLEDGE_AUDIT.md) |
| Відбій від рівня | є | sweep-reclaim + тригер закриття M15 |
| Підтискання / проторгівка | частково | `compression`/`attacks` в ORIGIN-тезі; окремого детектора підтискання до рівня немає |
| Імпульс | є | `_origin_events` (impulse, retrace) |
| Структурна інвалідація / структурний SL | є | `invalidation` = екстремум події; SL = екстремум − люфт (`level_luft`), ризик 0,15–6 %, ≥ MIN_STOP_ATR15 |
| TP за ліквідністю | є | `targets_for` від реальних рівнів, перешкоди перед TP1 |
| SMC: sweep, BOS/CHOCH, FVG, OB, premium/discount, PDH/PDL, session H/L | є (shadow) | `office2/smc/`: спостерігач, на LIVE READY не впливає |
| Сесії | є | `learning/sessions.py` (мітка); блокування OFF_HOURS не вводиться |
| Часткові виходи | paper | моделі A/B/C у `office2/paper.py` — порівняння, не правило |

## Що додано в цьому пакеті
- Мітка торгової моделі за видом тези (`learning/models.py`: REJECTION / BREAKOUT_RETEST / ORIGIN_RETEST) — у learning-звіті (`model=…`), paper-позиціях і Mini App. На рішення Brain не впливає.
- Контрфактуальні варіанти V7 (структурний SL) і V8 (BOS-підтвердження входу) — **лише дослідження**, у LIVE не вмикаються до підтвердження на незалежних періодах.

## Не реалізовано (потребує окремого дослідження, не вигадуємо)
- Оцінка сили рівня за кількістю тестів/реакцій/обсягу/свіжості (Герчик) і дзеркальні рівні.
- Детектор підтискання до рівня (компресія перед пробоєм) як окремий етап BREAKOUT.
- Фіксація 30/40/30 за ринковими цілями замість процентів — лише paper-порівняння.
