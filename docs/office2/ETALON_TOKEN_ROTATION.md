## Порядок (виконує власниця; Claude токен не бачить)
1. Переконатись, що в логах etalon (Render → Logs) пошук `bot` + `api.telegram.org` порожній. Якщо ні — спочатку PR #1 (httpx WARNING) після окремого погодження на merge.
2. BotFather → `/mybots` → бот etalon → API Token → **Revoke current token**. Старий токен одразу перестає працювати.
3. Render → etalon (srv-d7b9jbedqaus73ajgurg) → Environment → змінна з токеном (`TELEGRAM_BOT_TOKEN`/як названа в сервісі) → вставити новий токен → Save (запускає перезапуск, коротка пауза etalon).
4. Перевірка: у логах старт без `401/Unauthorized`, бот відповідає на `/start`; токен у логах не з'являється.
5. Нові токени не вставляти в чат; якщо вставлено — повторити крок 2.
