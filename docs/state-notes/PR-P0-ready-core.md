# P0: ядро «Плану готовий» (ідентичність ідеї, заморожений план, повідомлення = гейт, події рівнів)

Підстава: аудит `docs/audit/OFFICE2_POST_LAUNCH_AUDIT_2026-10-04.md` + звірка з експортом Telegram.

| Проблема (корінь) | Виправлення |
|---|---|
| Дублі READY: новий `scenario_id`/basis на H1/H4-закритті → той самий інструмент+напрямок+діапазон підтверджується двічі | `office_ready_core.find_duplicate`: незавершений (без SIGNAL_RESULT) READY тієї ж ідеї з журналу SIGNAL_PLAN блокує другий. Нова ідея після завершення (стоп/ціль) не блокується — без лімітів і охолодження |
| Наступний скан перезаписував вхід/стоп/цілі/статус CONFIRMED (`signal_upsert ON CONFLICT`) | `ON CONFLICT … WHERE status NOT IN (CONFIRMED, HIT_TP1, HIT_TP2)`; `signal_refresh_scenario` так само |
| Прихований/інший TP2: гейт брав записаний TP2, повідомлення — структурний | Одне джерело: записаний TP2 сценарію; TP3 лише разом із TP2 (немає TP1+TP3 без TP2) |
| Немає знімка входів гейта | `SIGNAL_PLAN.gate` (entry/SL/TP, risk, rr_net, rr_weighted, правило, комісія, мін. TP1, показані TP) |
| `is_major_symbol` по префіксу (ETHFI = ETH) | точний список баз BTC/ETH/XAU/PAXG після зняття котирування |
| TP/SL тихо без manual-open | `SCENARIO_MILESTONE`: «ціна досягла TP1/TP2/TP3/стоп-рівня сценарію» відповіддю на READY, один раз; лише READY після першого запуску (без лавини); не каже «угоду закрито» |
| «Діє до» без дати (час = часу отримання) | «Діє до ДД.ММ ГГ:ХХ (Київ)» |
| «Сценарій недоступний»: пошук лише серед останніх 200 рядків (1310 із 1364 READY за межею) | пошук за id прямо в БД |
| Нема кнопки «Сценарій» у 8% READY: bot-send таймаут 12 с → Telethon без кнопки | для повідомлень із кнопкою: таймаут 30 с + до 2 повторів Bot API |

Ризики: (1) при втраті відповіді Telegram на таймауті повтор може дати рідкісний дубль повідомлення (краще, ніж без кнопки); (2) milestone має лаг до закриття M15; (3) блок дубля — за діапазоном стоп…цілі старого плану, вхід поза діапазоном = нова ідея.
Не змінено: пороги RR/ATR/стопів/TP, Pine OFF, кнопка «Я відкрила угоду», ордери.
