# Anatomy для AI Office — експериментальна інтеграція

Джерело: https://github.com/wheresryan22/anatomy (MIT). Anatomy — відкритий agent skill для інтерактивних ізометричних SVG/WebGL-пояснень механізмів, а не бібліотека графіків або система прогнозування.

## Що додано
- [Інтерактивний макет](./anatomy-office-demo.html) для огляду MARKET DATA → ANALYST / RISK → READY/B&R.
- Усі описи в макеті пояснювальні. **Жодні реальні trading status, статистика чи API не підключені.**
- Змін production Worker, торгових правил, Render чи Mini App немає.

## Як забрати повний Anatomy skill до локального середовища
У корені AI Office (з доступом Git):
```sh
git clone https://github.com/wheresryan22/anatomy.git .claude/skills/anatomy
```
Перед установкою перевірити останній commit і ліцензію; для відтворюваності зафіксувати конкретний upstream SHA. Альтернатива для Claude Code:
```sh
npx skills add wheresryan22/anatomy -a claude-code
```
Повний skill **не vendored у цьому PR**: щоб він працював, потрібні `SKILL.md`, `kit/`, `references/` та `scripts/`, а не лише один файл. Рекомендовано окремо перевірити код і залежності, перш ніж запускати сторонні скрипти.

## Наступний інтеграційний етап (окремий PR)
1. Узгодити реальні API/дані для статусів модулів без розкриття ключів.
2. Додати read-only endpoint спостереження за свіжістю та здоров'ям даних.
3. Збудувати повноцінну 40+ частинну інтерактивну ізометричну фігуру засобами Anatomy kit.
4. Перевірити її скриншотами в браузері і аудитом геометрії, додати як lazy-loaded вкладку Mini App.
5. Запуск у production тільки після review, CI та окремого погодження.

Ця демонстрація навмисне простіша за повноцінний стандарт деталізації Anatomy. Жодних торгових дій вона не виконує.
