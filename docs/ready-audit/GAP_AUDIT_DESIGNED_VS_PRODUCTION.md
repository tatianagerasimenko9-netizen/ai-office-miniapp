## 0. Звідки взято «задумане»
- `docs/project-requirements.md` (постійні вимоги власниці): «від старших таймфреймів до молодших: напрям, структура, рівні, зони ліквідності → точка входу на меншому графіку»; методи — Вайкофф, ICT/SMC, OB, breaker, FVG/BPR, зняття ліквідності, хибні пробої, відбої, повторні перевірки, рівні дня/тижня, PDH/PDL; **«кожен використаний метод впливає на рішення; перелік термінів без впливу заборонений»**; «План готовий» — лише коли одночасно виконані всі обов'язкові умови (§7).
- `office_gerchik_kernel.py` (операційне ядро Герчика): рівень D1/сесійний/PDH-PDL; **«плаваючий і середина діапазону — не вхід»**; одна модель (відбій / пробій / хибний пробій); ATR day_used ≥75–80 % → не по тренду; RR ≥ 3, інакше «не сетап Герчика»; **шар Б — бал 0–10** (рівень +2, sweep/ЛП +3, ATR<70 % +2, імпульс/BOS +1, обсяг +1, M15 +1; 0–4 пропуск).
- Задум власниці в діалозі: ієрархія **місяць → тиждень → 4д → 3д → 1д → 4г → … → мінімальний ТФ**, далі SMC/ICT, Булковскі, Вайкофф, OB/breaker, сильні й дзеркальні рівні; канал — додатковий. **У репозиторії ця ієрархія (місяць/4д/3д) ніде не формалізована** (є лише «від старших до молодших»).
- `office_worker_library/.../KONSPEKT_UA.md`: Булковскі — «контекст, не вхід; фінал за рівнями + підтвердженням + ризиком (Герчик)».
