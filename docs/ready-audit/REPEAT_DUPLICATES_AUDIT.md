## 4. Короткі стопи (природні плани із заморожених свічок, 72 плани)
- BNB 0,24% (стоп = 1,09 ATR15, 0,69 ATR1h, TP1/SL 16,5) → SL; ETHFI 0,34% (0,58 ATR15) → SL за 5 хв; KAITO 0,67% (1,13 ATR15) → SL за 21 хв; TSM 0,26%, INTC 0,40%, HAEDAL 0,55% (0,59 ATR15, TP1/SL 37) — ще без результату на 3 год «нічого».
- Групи за стопом: <0,7% — 0/6 TP при базі «блукання» 10,3%; 0,7–1,2% — 0/4 (18,1%); ≥1,2% — 1/15 (30,2%). За ATR15: <1,5 — 0/7 (12,9%); 1,5–3 — 1/12 (25,6%); ≥3 — 0/6 (29,4%).
- Висновок обережний: на 72 планах (вирішених 28) **немає даних, що спростовують попередній результат** (залежність від абсолютного % переважно геометрична; ATR-нормалізація може нести інформацію), але і підтвердити статистично не можна — і цензурування працює проти TP. Перевіряти на replay 4–5 жовтня.
- **Структурний механізм крихкого стопа:** обов'язкова дистанція TP1 ≥ 3% (`min_tp1_pct`) + будь-який дуже вузький стоп дає величезний RR (BNB 16,5, HAEDAL 37), тож RR-гейт проходить «автоматично», а ймовірність TP1 раніше SL при випадковій ціні лише r/(r+t) ≈ 1–6%. Тобто гейт RR сам стимулює вузькі стопи. Не змінюю, фіксую як гіпотезу для shadow.
