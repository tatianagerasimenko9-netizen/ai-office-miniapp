## Класифікація за вказівкою користувачки
1. **Методика Дарії Жданової**: навчальні матеріали, надіслані користувачкою сьогодні як методика Дарії; їх ідентифікувати за конкретним вкладенням, датою/послідовністю, текстом або вказівкою користувачки; не класифікувати авторство лише за стилем графіка.
2. **Герчик / SMC/ICT**: окремі книги й методички, їхнє авторство зберігається; можуть бути складовою навчальної бази, але це НЕ авторські тексти Дарії.
3. **Сторонні Telegram-приклади**: BTW SHORT від CRYPTO RICH BEARS та інші прямо позначені сторонні приклади — **референси корисності AI Office, повідомлень і супроводу**, а НЕ торгові правила Дарії.
4. **AI Office QA**: RUNE-картки з трьома стопами — перевірка власного продукту, НЕ методика.
5. Без надійної атрибуції: `NEEDS_SOURCE_MAPPING`.

**Увага:** попередній `INDEX.csv` містить тематичну, частково автоматичну класифікацію; НЕ вважати поле `category` доказом автора. Новий provenance override має вищий пріоритет.
