# Незмінні правила джерел для AI Office

Ці правила продиктовані власницею й мають пріоритет над стислими переказами попередніх AI.

## Атрибуція
- Навчальні скрини, надіслані 11.10.2026 як методика Дарії, розглядати в цій групі після встановлення відповідності оригіналів; не розсипати їх по папках «загальні графіки», «свічки», «інфографіка» як ніби це різні автори.
- Скріншоти BTW SHORT / CRYPTO RICH BEARS — лише приклади подачі плану та супроводу. Жодних % фіксації, стопів чи торгових правил не копіювати автоматично.
- RUNE AI Office — контроль продукту.
- Книги Герчика та SMC зберігають власних авторів; Вайкоффа, Елліотта, Фібоначчі, паранормальні бари пов'язувати лише з доступними авторськими джерелами.
- Невідоме походження -> `NEEDS_SOURCE_MAPPING`. Візуальний стиль лише підказка, не доказ.

## Правила торгівлі
- Жодних вигаданих умов, порогів, відсотків, торгових підтверджень, таймфреймів.
- Не змішувати авторські правила різних методик у одну «методику Дарії».
- За уточненням користувачки: в одному з її сценаріїв **сильна свічка СТАРШОГО таймфрейму -> відкат у її область -> пошук входу на меншому таймфреймі**. Фібоначчі будується на **старшому імпульсі**. Це вимога користувачки щодо тлумачення матеріалів; пов'язати з точними скриншотами перш ніж формалізувати числові пороги.
- Для кожного правила обов'язково: `rule_id, author, source_file, file_hash, page_or_frame, exact_evidence, timeframe, entry_conditions, invalidation, assumptions, status`.
- Якщо правило не доведено першоджерелом — `UNVERIFIED`; не включати в сигнал як авторський факт.
- Якщо джерело не встановлює числовий поріг, зберігати `NOT_SPECIFIED`, а технічну гіпотезу тестувати окремо з позначкою `OFFICE_HYPOTHESIS`.
- **No lookahead:** ознаки, рівні, swing/Fibonacci опори лише з інформації, доступної на момент рішення; backfill не називати первинним сигналом.

## Впровадження
- Проміжні стани: SOURCE_MAPPED -> RULE_EXTRACTED -> RULE_VERIFIED -> CODED -> REPLAY_PASSED -> SHADOW/PAPER_VALIDATED.
- Спочатку read-only аналіз, shadow, replay на реальних свічках із витратами, потім paper-forward. Без незалежних доказів переваги не міняти LIVE-логіку.
- Не вмикати реальні ордери, не послаблювати денний захист, не збільшувати LIVE-universe без окремого погодження.
- Telegram: максимум 3–5 перевірених причин, висновок людською мовою, кнопка на саме цю картку; Mini App: всі докази, старші та молодші ТФ, графік, стопи, історія.
- Антиспам: одна незалежна ідея -> одна картка, повідомлення лише на істотні події, молодші свічки не створюють десятки повторів.
