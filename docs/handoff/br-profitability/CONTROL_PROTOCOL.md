# Протокол контролю (як Claude перевіряє ChatGPT)
1. ChatGPT працює лише за `MASTER_CHECKLIST.md`; кожен коміт/PR починається з ID (`A4: …`). Нічого поза чеклистом без запису в `STATUS_LOG.md` з причиною.
2. Результат ChatGPT = файли в репозиторії (`analysis/…`, патчі/PR), а не текст у чаті. Звіт — за форматом у PROMPT_FOR_CHATGPT.md.
3. Claude на кожному циклі (≈ щогодини до 19:00 Київ): `git log` гілок, статус CI, diff на заборонені зони (LIVE-гейти, ризик, ордери, Binance-пейсинг), запуск тестів, перевірка прод-логів/БД після деплою. Результат — рядок у `STATUS_LOG.md` (час, ID, що перевірено, доказ).
4. Приймання пункту: тест/CI зелений (або відомо-червоний за розділом C чеклиста), diff без заборонених зон, для прод-пунктів — доказ у проді. Інакше повернути з конкретною причиною.
5. Merge у main робить лише Claude; пункти, що змінюють поведінку прода, — після явної згоди власниці.
6. Якщо ChatGPT пропустив пункт чеклиста або виправив «на папері» (без коміту/тесту) — статус лишається TODO, у `STATUS_LOG.md` фіксується пропуск.
