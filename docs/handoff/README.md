# docs/handoff — папка передачі задач між агентами

Робочий формат власниці: Claude (Code) готує папку `docs/handoff/<задача>/`, власниця дає ChatGPT короткий промпт, ChatGPT читає папку з репозиторію, виконує, повертає звіт (власниця переносить його назад). Кожна папка: `README.md` (коротко), `PROMPT_FOR_CHATGPT.md` (повне завдання), `FINDINGS_SO_FAR.md`, `STATUS_NOT_DONE.md`, дані/скрипти.
Правила: `docs/strategies/SOURCE_RULES.md`; без автоторгівлі, без зміни LIVE-гейтів/ризику; нове — спершу shadow/paper.

Задачі: `br-profitability/` — прибутковість B&R (сесії/години, стопи за структурою старшого ТФ).
