## Висновки без вигадування
1. Із 14 методів лише №5 (паранормальний рух → база) і №10 (рівні Фібоначчі) мають **числові** умови з джерела; №1 і №2 мають чітку **послідовність**, але без чисел. Усе інше — якісні критерії.
2. Для методів №2–4, 6–8, 11–14 перед будь-яким детектором потрібні вимірювані визначення від власниці (ТФ, що вважати «сильним імпульсом», «реакцією», «підтисненням»). Без них будь-який код був би вигаданим правилом.
3. Тестувати можна лише те, що Office реально виробляє як сценарій: хибний пробій (картки) і паранормальна база (shadow). Решта методів лишається `SOURCE_REGISTRY_ONLY` до уточнень.
4. Жодна частина методики не показала доведеної прибутковості: журналу угод у джерелах немає.
