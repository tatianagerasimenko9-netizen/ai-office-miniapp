# Реєстр першоджерел AI Office (пакет «Dzherela 2026-10-12»)

Що тут: **індекс і докази**, не самі матеріали. Оригінали (415 зображень, текст книги Герчика, методичка SM Trader, docx-конспект) лежать у приватному середовищі власниці і **не** комітяться в публічний GitHub.

| Файл | Зміст |
|---|---|
| `manifest.csv` | 427 записів: 415 зображень + 12 файлів пакета (шлях у архіві, SHA-256, автор встановлений чи ні, тип, тема, якість читання, результат, `rule_ids`) |
| `evidence.jsonl` | Правила за методами: `rule_id`, автор, файл/сторінка/кадр/рядки, коротка парафраза, умови, інвалідація, чого бракує, припущення автоматизації (окремо, `IMPLEMENTATION_HYPOTHESIS`), статус реалізації, відповідність коду, `last_audit_commit` |
| `unresolved.md` | Що не підтверджено, конфлікти джерел, що прочитано не повністю |
| `METHOD_MAP_DARIA.md`, `METHOD_MAP_GERCHIK.md`, `METHOD_MAP_SMC.md` | Короткі карти методів: послідовність, числа з джерела, чого немає в джерелі |
| `CONFORMITY_2026-10-12.md` | Звірка параметрів коду з джерелами (збігається / відрізняється / гіпотеза) |

Типи джерел: `DARIA_METHOD`, `GERCHIK`, `SMC`, `OTHER_VERIFIED`, `OFFICE_UX_EXAMPLE` (BTW/CRYPTO RICH BEARS — лише подача), `OFFICE_PRODUCT_QA` (RUNE/картки Office — лише QA), `NEEDS_SOURCE_MAPPING`.

Пріоритет доказів автора: пряме визначення власниці → автор на зображенні → контекст завантаження → тема. Стиль картинки — не доказ. `INDEX.csv` з пакета — лише тематичний.

Перевірка: `python3 scripts/test_sources_registry.py` (CI offline): 427 записів, унікальні шляхи, SHA-256 формат, обов'язкові поля правил, SHA джерел правил ∈ manifest, немає бінарних оригіналів у `docs/sources`.

Правило: немає запису в `evidence.jsonl` з класом `SOURCE_*` → не є авторським правилом; торгова логіка без такого запису = `IMPLEMENTATION_HYPOTHESIS` / `USER_REQUIREMENT` і працює лише в shadow/paper.
