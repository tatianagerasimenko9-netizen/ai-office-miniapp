# Герчик — карта методу (книга «Курс активного трейдера», 2019)

Файл: `sources/GERCHIK_BOOK.txt` (SHA у `manifest.csv`; у GitHub не публікується). Параграфи/сторінки — друковані; рядки — у текстовому файлі.

## Послідовність (за книгою)
1. Сильний рівень на D1 (с.56–66): лімітний (≥3 удари, без пробою), зламу тренду, історичний, дзеркальний, паранормальної свічки (≥2× середнього), проторговки, гепа; підсилювачі: дотики, недобій, хибний пробій, довгі хвости, кругла ціна (≈+20%).
2. Рух біля рівня (с.73–91): пробій / відбій / хибний пробій; сигнал — закриття; підтвердження — імпульс (2–3× середньодобового); не заходити посеред руху; поджаття; прогнозні ознаки.
3. Ризик (с.92–112): R:R ≥3:1; розрахунковий стоп 0,1–0,2% ціни (акції), крипта до 2% і лише технічний стоп; люфт ≈20% стопа; технічний стоп ≤ розрахунковий +20% (+30% для ЛП двома барами); ATR = 3–5 D1 без паранормальних; вето 75–80% ATR; запас ≥5 стопів; канал ≥6–8 стопів; ризик 1–3%/день (0,5–1%/угоду), 3 збитки поспіль → стоп на сесію.
4. Стратегії (с.117–147): відбій (БСУ/БПУ1/БПУ2), пробій, хибний пробій (1 бар / 2 бари / 3+), тейк і супровід, додавання обсягу.
5. Алгоритм і сценарії (с.171–191), крипта (с.179–183): технічний стоп, BTC як контекст, лімітні заявки, приклад балів студентів (не правило).
6. Розділ 6 (с.149): Фібоначчі/Еліотт/осцилятори **не** входять у методику.
