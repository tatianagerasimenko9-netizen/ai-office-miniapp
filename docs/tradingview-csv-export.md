# Як вивантажити CSV з TradingView для звірки індикаторів

1. Відкрий одну монету і один таймфрейм (напр. BTCUSDT.P, 15m).
2. Додай на графік потрібний індикатор (ICT SMC HUNTER або інший) з тими налаштуваннями, що в Pine за замовчуванням.
3. Угорі графіка: назва графіка (стрілка) → **Export chart data…** (потрібен платний план TradingView).
4. У вікні: Time format — ISO time; постав галочку, щоб увійшли значення індикаторів. Натисни Export.
5. Надішли CSV і повний код Pine цього індикатора — я звірю Python з Pine і виправлю розбіжності.
